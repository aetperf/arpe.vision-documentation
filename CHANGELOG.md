# Changelog

All notable changes to Arpe.Vision extensions will be documented in this file.

---

## [3.0.0] - 2026-10-08

New features and improvements for the latest version of the Arpe.Vision Tableau visualization extensions.

### Visualization Extensions

Our extensions are now available as **visualization extensions** (in addition to the dashboard extensions) and can be added directly within worksheets.

Available extensions:
- Sankey
- Sunburst
- Tree
- Radar

Visualization extensions provide better tooltip handling and improved dashboard integration, as they rely on Tableau's native actions.

### License Management
- Introduced a license management system.
- Strengthened security and privacy (no client information visible in logs).

### Design & User Experience
- New visual identity using the Arpe.vision colors.
- Interface aligned with the new website.
- New menu to hide icons.
- Fixed visualizations that appeared cut off or truncated.
- General optimization of the interface and navigation.

### Visualization Customization
- Real-time live preview while customizing.
- Warning message when closing an unsaved customization.
- Color selection through a color picker.
- Font size customization.

### Improvements by Visualization

**Sankey / Circular Sankey**
- Better highlighting and filtering.
- Fixed synchronization issues.
- Fixed display and automatic centering.
- Fixed filtering.

**Tree**
- Improved display on creation.
- No more data reloading during highlighting (smoother experience).

**Sunburst**
- Fixed highlighting.
- Improved coloring.

**Radar**
- Fixed data mapping.
- Adjusted height for better display.

### Tutorials & Documentation
- New tutorials and improvements to existing ones.
- Tutorials integrated in HTML format for better readability.
- Updated links to the new website.

### Miscellaneous Fixes
- Fixed parameter switching.
- Fixed scrollbars and display on Radar and Sankey.
- Fixed resizing issues.
